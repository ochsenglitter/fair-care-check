# Fenja Add-ons

Die Add-ons erweitern Fenja um spezialisierte Mental-Load-Systeme.

**Arbeitspreis pro Add-on:** ca. 19–29 € einmalig.

| Add-on | Bereich | Datei |
|---|---|---|
| Meal Planning | Essen | `meal-planning.md` |
| Travel & Packing | Reisen / Packen | `travel-und-packing.md` |
| Christmas | Weihnachten | `christmas.md` |
| Home | Haushalt | `home.md` |
| School Holidays | Ferien | `school-holidays.md` |

## Regel für neue Add-ons

Ein neues Add-on entsteht nur, wenn es die Filterfrage beantwortet:

> „Welchen konkreten Mental Load muss eine Mutter danach nicht mehr selbst
> übernehmen?"

Ein Add-on ist nie eine freigeschaltete Funktion von Fenja, sondern immer ein
eigener, abgrenzbarer Lebensbereich.
